# ProjectLite

簡易好用的工程專案排程工具。打開網頁就能用，不需安裝、不需登入。

- **WBS 任務樹**：階段與細項，縮排升降階、摺疊展開
- **CPM 排程**：自動算出最早/最晚開始完成、浮時與關鍵路徑
- **四種前置關係**：FS、SS、FF、SF，可加 Lag（延後）或 Lead（提前）
- **工作日曆**：週休二日、週休一日或全年無休，扣除國定假日，可設補班日
- **進度追蹤**：資料日期、完成百分比、實際開始/完成日
- **基準線**：存下原訂排程，之後比較落後幾天
- **甘特圖**：日/週/月刻度、相依線、非工作日底色、資料日期線
- **其他**：復原/重做、民國/西元切換、深色模式、匯出 CSV（Excel 可開）、列印 PDF
- **資料存在自己的瀏覽器**，可匯出 / 匯入 `.json` 備份檔

## 使用方式

打開網頁後會先看到範例專案。要建立自己的專案：

1. 「檔案 → 開新專案」，在專案設定填開始日、每週工作天和假日。
2. 「＋ 新增任務」建立工作項目；雙擊名稱或工期可以直接修改。
3. 雙擊任務開啟編輯欄，加入「前置任務」，排程會自動算好。

網頁右上角的「?」有完整說明、名詞解釋與快捷鍵。

> 資料只存在這台電腦的這個瀏覽器裡。換電腦、換瀏覽器或清除瀏覽資料前，請先「檔案 → 匯出備份檔」。

## 開發

需要 Node.js 20 以上。

```bash
npm install      # 安裝開發工具（只需第一次）
npm run dev      # 開啟本機開發伺服器，修改程式碼會即時更新
npm test         # 執行自動測試
npm run build    # 打包成可上線的檔案，輸出到 dist/
```

推送到 `main` 分支後，GitHub Actions 會自動測試、打包並發佈到 GitHub Pages。

## 程式架構

```
src/
  model/            資料與計算，和畫面無關
    types.ts        資料長什麼樣子
    dates.ts        日期換算
    calendar.ts     工作日曆
    schedule.ts     CPM 排程引擎
    store.ts        資料倉庫：所有修改、復原、存檔
    sample.ts       範例專案
    holidays-tw.ts  台灣國定假日
  ui/               畫面
    app.ts          畫面總指揮
    table.ts        左側任務表
    gantt.ts        甘特圖
    drawer.ts       任務編輯欄
    dialogs.ts      設定、說明、匯出匯入
  main.ts           程式進入點：按鈕與快捷鍵
tests/              自動測試
docs/學習筆記.md     給非工程背景的說明
```
